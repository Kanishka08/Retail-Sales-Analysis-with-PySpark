# 🛒 Retail Sales Analysis with PySpark

## 📌 Project Overview
This project demonstrates **big data handling, feature engineering, and machine learning modeling** using **PySpark** on a retail sales dataset.  
The goal is to predict sales based on historical transaction data while showcasing the ability to process and analyze large datasets in a scalable environment.

---

## 🎯 Objectives
- Load and process retail sales data using **PySpark**.
- Perform **feature engineering** (date extraction, aggregations, groupings).
- Build a **Linear Regression model** to predict sales.
- Evaluate model performance using metrics (RMSE, R²).
- Visualize predictions vs. actuals.

---

## 📊 Dataset
- **Source:** [Retail Sales Dataset - Kaggle](https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset)

---

## 🛠️ Tech Stack
- **Databricks (Azure)** – Big data environment
- **PySpark** – Data processing & ML
- **Python** – For evaluation and visualization
- **Matplotlib** – Charts for predictions vs. actuals

---

## 🚀 Workflow
1. **Load Data**: Read CSV into PySpark DataFrame.  
2. **Feature Engineering**: Extract date parts (year, month, day), aggregate sales.  
3. **Modeling**: Train a **Linear Regression model** with PySpark MLlib.  
4. **Evaluation**: Check metrics (RMSE, R²).  
5. **Visualization**: Plot predicted vs. actual sales using Matplotlib.  

---

## 📈 Results
- The Linear Regression model provides a baseline for sales prediction.
- Demonstrates ability to build an **end-to-end PySpark ML pipeline**.
- Visual comparison between **predicted vs. actual sales** included.
